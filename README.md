# ☕ Domain-Driven Design com Java

---

## 📘 Sobre o Repositório

Este repositório foi criado para armazenar os exercícios e projetos desenvolvidos na disciplina **Domain-Driven Design using Java**, cursada na faculdade.

O foco principal é o aprendizado prático de **Programação Orientada a Objetos (POO)** aliado aos conceitos de **DDD (Domain-Driven Design)**, com versionamento utilizando o GitHub.

---

## 🎯 Objetivos de Aprendizado

- Desenvolver habilidades em **Java**
- Aplicar conceitos de **Programação Orientada a Objetos**
- Entender e implementar **Domain-Driven Design (DDD)**
- Praticar versionamento com **Git e GitHub**
- Criar código limpo e organizado seguindo boas práticas

---

## 🧠 Conceitos Abordados

### ☕ Java & POO
✔️ Classes e objetos  
✔️ Encapsulamento  
✔️ Herança  
✔️ Polimorfismo  
✔️ Abstração  
✔️ Métodos e atributos

### 🧩 Domain-Driven Design (DDD)
✔️ Entidades (Entities)  
✔️ Objetos de Valor (Value Objects)  
✔️ Agregados (Aggregates)  
✔️ Repositórios (Repositories)  
✔️ Serviços de Domínio (Domain Services)  
✔️ Linguagem Ubíqua (Ubiquitous Language)

## ▶️ Como Executar os Projetos

### 1. Pré-requisitos
- Ter o Java instalado (JDK 8 ou superior)

Verifique com:

java -version

### 2. Compilar o código:

javac NomeDoArquivo.java

### 3. Executar:

java NomeDoArquivo
